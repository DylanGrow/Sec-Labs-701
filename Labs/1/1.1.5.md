# Lab 00: Exploring the Lab Environment

### Security+ (SY0-701) • Key & Solutions

---

### 1. VM Identification

> **Question:** What is the name of the Kali VM?

* **Answer:** kali

---

### 2. Network Interface Verification File

> **Task:** Create the network configuration output file in the root directory.

* **Command:**
```bash
cd /root && ip a | grep eth0 > eth0_Config.txt

```



---

### 3. IPv4 Address Extraction

> **Question:** Please enter the inet address for `eth0` from `eth0_Config.txt` *(do not include the slash or CIDR mask)*.

* **Answer:** 10.2.17.77 *(or your dynamically assigned IP, e.g., `192.168.1.100`)*

---
